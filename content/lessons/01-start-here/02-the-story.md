# One story, not six labs

Slide decks split headless into topics: MVC, SXA, JSS, Edge, Search. This workshop keeps one object in view the whole way: a homepage hero.

## The path

| Stop | What changes | What stays |
| --- | --- | --- |
| This portal | Lessons are React plus markdown | The hero is hard-coded |
| MVC | You name the rendering, the view, and the datasource | Authors edit fields in Experience Editor |
| SXA | The site gets a skeleton: tenant, designs, placeholders | The hero is still a rendering in a placeholder |
| JSS | The same placeholder comes back as JSON | React draws the hero |
| Capstone | You edit layout data and the banner moves | The component code does not |

## Official references you will keep using

- [Sitecore JavaScript Rendering SDK (JSS) for React](https://doc.sitecore.com/xp/en/developers/hd/22/sitecore-headless-development/sitecore-javascript-rendering-sdk--jss--for-react.html), the 22.x docs that match Headless Rendering for XP 10.4
